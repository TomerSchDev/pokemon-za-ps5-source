# בדיקת התיקון לטקסטורות בקונסולה (טיוטה לפרק של r28a ב־TEST-HE.md)

**לסוכן שמפעיל את הקונסולה, בתיאום עם Tomer. משך: 30–45 דקות.**

## 0. לפני ההתחלה
- **ההתקנה:** לפי הוראות ההתקנה של r28a: המשחק סגור, גיבוי מאומת של השמירה, eboot בלבד, `.new` → readback → rename → readback.
- **הקלטה:** מפעילים את קליטת ה־klog **לפני** הפעלת המשחק, ומשאירים אותה פעילה עד שהמשחק נסגר.

## 1. אימות שהבנייה הנכונה רצה
- **בעלייה:** מופיעה ב־klog פעם אחת השורה `[za-texguard] r28a texfix active: live list locked, finalized textures guarded and quarantined (4096), present under exec_lock`.
- **אם השורה חסרה:** זה לא r28a. עוצרים, ומחזירים את הגרסה הקודמת לפי ההוראות.

## 2. המשחק (Continue לריצה הפעילה; לא פותחים ריצה חדשה בלי Tomer)
מבצעים מעברי סצנה רבים, ורושמים שעה בקירוב לכל מקבץ:
- כניסה ויציאה מבניינים: לפחות 10.
- כניסה ויציאה מ־Wild Zones: לפחות 5.
- קרבות: לפחות 5 עם פוקימונים בטבע, ועוד קרב מאמן אחד אם יש.
- פתיחה וסגירה של תפריטים: לפחות 20. תפריט X ודפיו, המפה, ה־Pokédex, התיק ותפריט L3+R3 (FPS TRIAL, ITEMS).
- נסיעה מהירה (Flying Taxi): לפחות 5.
- שמירה במשחק: לפחות 3.
- פעם אחת לפחות: יציאה מסודרת מהמשחק, הפעלה מחדש ו־Continue. זו טעינה.
- הליכה ברחובות עם שמיים פתוחים, שבהם הופיעו הצורות הכהות בעבר. בהתאם לזמן במשחק, גם בשעות שונות של היום.

## 3. מה אוספים
- **klog:** כל ה־klog מהעלייה ועד הסגירה, אל `evidence/r28a-hardware-<תאריך>/all.klog.log`.
- **שורות האבחון:** כל שורה שמתחילה ב־`[za-texguard]`, חוץ משורת ה־active. אלה כוללות שורות `... is not live ... (caller 0x..., frame N)` ושורות `counts at frame N: ...`.
- **קריסה:** כל `[za-native-fault]` או `signal 11`, עם 40 השורות שאחריהן (backtrace).
- **צורות כהות או זבל בשמיים:** תמונה, שעה ומקום. יש לציין אם הופיעו או שלא הופיעו.
- **ביצועים:** הקצב, כרגיל, משורות `[vk] t=... fps`.

## 4. דיווח ל־Tomer (בעברית)
- קריסה: כן או לא, ואם כן אז המיקום.
- שורות `[za-texguard]`: לכל אתר את ה־caller, ה־frame והספירה האחרונה.
- צורות בשמיים: כן או לא.
- הקצב, בהשוואה ל־r28.

## 5. פענוח caller
מחסירים מהכתובת את הבסיס 0x400000, ומפענחים מול ה־PIE של r28a:

```
llvm-symbolizer --obj=<r28a>/llvm-pie.elf 0x<caller-0x400000>
```

- caller ‏`(nil)` פירושו שהאתר עצמו מזהה את המקום. האתרים: `set-render-targets`, `render-pass`, `clear-texture`, `copy-*`, `finalize-again`, `pool-register`.
