## ביטויי מילים להשוואה

כל אחת משבע קטגוריות ההגדרות מציגה ביטוי קבוע בן ארבע מילים קצרות, כגון `Birch-Creek-Spring-Nut`.
מסך האישור ו-Saved Runs מציגים גם את הביטוי הכולל לצד ה-seed. אותו seed ואותו ביטוי כולל,
באותו תחום אלגוריתם ומשחק, משחזרים אותה ריצה. שם המאמן משפיע על Player ועל הביטוי הכולל.

הפרוטוקול `za-settings-words-1` כולל גרסת מילון ו-SHA-256 שלו, אלגוריתם הגנרטור ו-build id.
ה-seed אינו חלק מהביטויים. המפרט ב-`src/settings_codes.h`; וקטורים עצמאיים ב-`test/test_settings_codes.cpp`.
`report.json.settings_codes` שומר שבע קטגוריות, ביטוי כולל ואת מטא-נתוני הגרסאות והמילון.
ריצות ישנות ללא הגדרות מלאות מציגות `Phrase unavailable`.

  --out /home/tomer/ps5-za-native/r29ui-NEW \
  --package /mnt/c/PATH-TO-REPO/artifacts/randomizer-r29-ui-NEW \
  --assets /home/tomer/ps5-za-native/rando-v3-codex-m1-assets
