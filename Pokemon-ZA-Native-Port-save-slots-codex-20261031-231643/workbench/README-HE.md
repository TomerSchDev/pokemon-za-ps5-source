# שולחן העבודה של Z-A — `zw`

המקום האחד לבנייה, הרצה ובדיקה של המשחק: עברית, מינים חדשים, FPS, צ'יטים, רנדומייזר, בנייה והתקנה.
`zw` לא מחליף את הכלים הקיימים. הוא מפנה כל פקודה לסקריפט שאחראי לה, כך שכל הבדיקות של הכלי נשמרות.

## איך נותנים משימה לסוכן (הכי זול בזיכרון ובזמן)

1. מריצים מהריפו: `.\zw brief <משימה>`. מקבלים טקסט מוכן להדבקה: הכללים, ואחריהם רק הכרטיסים שהמשימה צריכה.
2. מדביקים אותו בתחילת הפרומפט של הסוכן, ומתחתיו כותבים את המשימה עצמה.

| משימה | `zw brief …` | מה הסוכן מקבל |
|---|---|---|
| עברית | `hebrew` | כללים, mods, עברית, הרצת PC |
| עוד פוקימונים | `species` | כללים, mods, מינים, הרצת PC, אטלס |
| FPS / ביצועים | `fps` | כללים, FPS, מדידה בקונסולה, הרצת PC, בנייה, אטלס |
| צ'יט / אפשרות רנדומייזר | `cheat` / `randomizer` | כללים, רנדומייזר, אטלס, בנייה, הרצת PC |
| בניית eboot | `build` | כללים, בנייה, התקנה |
| התקנה בקונסולה | `install` | כללים, התקנה, מדידה בקונסולה, קריסות |
| קריסה | `crash` | כללים, קריסות, אטלס, מדידה בקונסולה |
| בדיקת QA בקונסולה | `console-qa` | כללים, מדידה בקונסולה, FPS, קריסות |

ה־brief של משימה הוא כ־1.5–3.5 אלף tokens, במקום עשרות אלפים כשהסוכן קורא את כל מסמכי ההעברה. הכרטיסים כתובים באנגלית בכוונה: עברית עולה בערך פי 2 ב־tokens. מסמכי המחקר המלאים עדיין קיימים, וכל כרטיס מפנה אליהם רק "אם צריך".
סוכן שצריך עוד מידע מריץ בעצמו `zw card <שם>`.

## הפקודות

| פקודה | מה היא עושה | קונסולה? |
|---|---|---|
| `zw doctor` | בודקת שכל הכלים, הנתונים והנתיבים קיימים | לא (עם `--console-ok` בודקת גם פורטים) |
| `zw atlas find/str/fn/who-calls/annotate …` | חיפוש בקוד המשחק המתורגם | לא |
| `zw crash LOG --elf …` | פענוח קריסה מ־klog | לא |
| `zw za verify/reproduce/build …` | בנייה ושחזור של eboot (WSL) | לא |
| `zw pc run NAME --seconds N [--fps 60] [--shot-at …] [--input …] [--mods DIR]` | הרצה תחומה של גרסת ה־PC עם צילומים | לא |
| `zw pc shots NAME` / `zw pc fps NAME` | רשימת הצילומים / סיכום FPS של הרצה | לא |
| `zw hebrew <כלי> …` / `zw species <כלי> …` | מריץ כלי מ־hebrew-lab / species-lab | לא |
| `zw queue status/enqueue/claim …` | תור ההתקנות המשותף (מקומי) | לא |
| `zw shot --out DIR` | צילום מסך מהקונסולה | כן |
| `zw fps measure 20 --out DIR` / `zw fps set 1` | מדידת FPS / בקשת 60 | כן |
| `zw input A 4` | לחיצת כפתור במשחק | כן |
| `zw klog --out FILE --seconds 60` | לכידת לוג מהקונסולה | כן |

כל פקודה שפונה לקונסולה **מסרבת** בלי `--console-ok`, כך שסוכן לא יגע בקונסולה בטעות. מוסיפים את הדגל רק בסשן שתיאמת.

## מבנה

```
zw.cmd                    כניסה מהריפו (Windows; משתמש ב־py -3)
workbench/zw.py           המפנה
workbench/cards/*.md      כרטיס לכל נושא: rules, atlas, build, console-install, console-observe,
                          crash, fps, hebrew, mods, pc-run, randomizer, species
workbench/test_zw.py      בדיקות (py -3 -I workbench/test_zw.py)
AGENTS.md, CLAUDE.md      הפניה קצרה לכאן לכל סוכן שנפתח בריפו
```
