r27-play — שם מאמן וצ׳יט כסף לרנדומייזר Z-A

הגרסה נבנית על r26p1. היא שומרת על FPS TRIAL, מונה FPS, הגשת הציור בתהליך נפרד, עומק תור 64, הקומפיילר ומטמון השיידרים הקיימים. אין בה שינוי תזמון חדש או תרגום לעברית.

שם מאמן:
בתפריט הרנדומייזר בחר NAME, הזן עד 12 תווים במקלדת ואשר DONE. השם יוחל על ריצה חדשה בלבד ועל שם המאמן המקורי של הפוקימונים השייכים לה. Continue ו־Saved Runs שומרים על הריצות הקיימות כפי שהן. מותרות אותיות לטיניות, מספרים, רווח וחלק מסימני הפיסוק; מקש Triangle מחליף אותיות גדולות/קטנות.

כסף:
בתוך המשחק לחץ L3+R3, עבור ל־MONEY ובחר עם ימין/שמאל תוספת של 10,000, 100,000 או 1,000,000. לחץ X פעם אחת. QUEUED מציין שהבקשה ממתינה; ADDED מציין שהמשחק החיל תוספת. סגור את תפריט הצ׳יטים ופתח את תפריט המשחק או שמור מתוך המשחק. שמירה שומרת את הסכום גם להפעלה הבאה.
בבדיקת המחשב כותרת הכסף בתפריט שמרה את המספר הקודם בפתיחה הראשונה, אף שהתוספת כבר הוחלה. סגירה ופתיחה נוספת של תפריט המשחק מרעננות את המספר המוצג.
בקשה אחת יכולה להמתין בכל רגע. שינוי הסכום או בחירה ב־NORMAL מבטלים בקשה שטרם הוחלה. טעינת שמירה/אתחול מחזירים את הצ׳יט למצב כבוי. סכום שכבר הוחל אינו מוסר בבחירה ב־NORMAL. התקרה היא 9,999,999.

בנייה:
bash port/perf-r27/build-r27-play.sh build
לאחר בדיקת משחק אמיתית במחשב: bash port/perf-r27/build-r27-play.sh package /absolute/path/to/pc-proof.json
האריזה מאמתת שהמקורות שנבדקו במחשב זהים למקורות הבנייה. היא משווה את הרכיבים והקבצים לגרסת r26p1 ודורשת שהשינוי בחבילת האפליקציה יהיה eboot.bin בלבד.

התקנה:
המתקין port/perf-r27/install_r27.py מיועד ל־PPSA91762 בלבד, כשהמשחק סגור. הוא מגבה את השמירה העדכנית ואת התוכנית הקודמת, מאמת SHA-256, מעביר קובץ זמני, קורא אותו חזרה, מחליף ומאמת שוב. קובצי האפשרויות והשמירות אינם מוחלפים. rollback מחזיר רק את התוכנית המקורית המאומתת ואינו תלוי בעותק החבילה החדשה.

מצב הבדיקות וההתקנה בפועל מופיע בדוח התוצאות הנלווה; עצם קיומו של קובץ זה אינו אישור שהגרסה כבר הותקנה בקונסולה.
