# r26p1 — תיקון בחירת 60 FPS

ב-r26p המקורית שורת FPS TRIAL הייתה חסרה, למרות ההנחיה שהופיעה בתיעוד. FPS COUNTER מפעיל ומכבה את
התצוגה בלבד. התיקון מחזיר את השליטה בניסיון 60 דרך התפריט.

1. לחיצה פנימה על שני הסטיקים יחד: L3+R3.
2. בחירת השורה FPS TRIAL בחיצים. היא נמצאת מתחת ל-FPS COUNTER ומעל RESET.
3. X מתחיל ניסיון 60. עיגול סוגר את התפריט.
4. X נוסף באותה שורה מחזיר למצב המקורי, 30.

אם הקצב נמוך במשך חלונות מדידה נקיים, מנגנון r16 הקיים חוזר אוטומטית ל-30. בשורה יוצג
`30 FALLBACK - X RETRY`; אפשר לנסות שוב באזור קל יותר. התיקון מחזיר את הבחירה ואינו מבטיח 60 בכל אזור.
הניסיון תקף להפעלה הנוכחית בלבד. אחרי פתיחת המשחק מחדש מתחילים ב-30.

העדכון מיועד רק ל-PPSA91762. הוא מחליף רק את eboot.bin; קובצי האפשרויות, שמירות והגדרות צ׳יטים אינם
מוחלפים. אין לשחזר שמירה ישנה. לפני החלפה נדרש לסגור את המשחק ולגבות את השמירה העדכנית ואת הבינארי
המותקן. העלאה כ-eboot.bin.new, אימות SHA-256, rename ואימות נוסף.

SHA-256 של eboot.bin בתיקון:
`c382275b90704d50e50e57875116bd69341e6c6b9c9c4e4d43223b367e19f7fa`

הבנייה, הבדיקות ודוח ההתקנה הנפרד מפרטים אילו בדיקות בוצעו במחשב ואילו בקונסולה.
